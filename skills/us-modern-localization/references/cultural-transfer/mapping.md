# 现代美国都市功能映射

## 目标世界基线

所有来源题材统一转置为现代美国都市现实背景。原作时代只作为来源分析字段，不决定输出分支；不再选择欧洲中世纪、古代王国或超自然世界。先锁定美国城市及都市圈、当代时间范围、社会组织、职业权限、交通通信、教育、司法、医疗与金融基线。可使用虚构的美国城市或企业，但不能借虚构地名引入封建法权或魔法规则。

若需州法/地方权限支持剧情，确定州与地方层级或采用不依赖精确州法的保守表述，不虚构全国统一程序。所有关键人物关系与事件在现代生活条件下成立：手机、监控、电子记录与现代交通会影响失联、取证和赶路；不能只换地名而保留古代的通信真空。支线短暂离开城市也必须服务都市主线，不能另开古代或异世界叙事。

宗教、传说、历史文物可以是现代人物的信仰、谈论或展览内容，但不作为已被证实的超自然力量推动结果。涉及奇幻机制时执行下方现实化规则。

## 先问功能，再选载体

对每项元素写清：原物是什么 → 谁凭它能做什么 → 它造成的阻碍、证据、情绪或身份作用 → 哪些条件不能动 → 目标世界有什么可承担同样作用 → 是否牵动后文。替换后逐条检验条件，而非只检查词义相近。

识别范围包括：姓名/别名/称谓、地名与地理尺度、机构和职业、法律和社会身份、教育与阶层、医疗保险及救治、金融债务及财产、户籍档案、民族/宗教/神话、民俗节庆、婚丧嫁娶、家庭称谓与礼序、饮食衣着建筑、语言双关与成语典故、货币计量、书信印章及关键物件。叙述、对白、人物OS、章名、题记和引文都检查。

## 映射台账字段

每条保存：稳定编号｜类别｜来源正式名称｜来源别名及定位｜原剧情功能｜锁定目标实体与中文名称｜目标称谓/别名规则｜时代地域｜保持条件｜涉及章节/伏笔｜替换理由｜专业不确定性｜状态与版本。

- 同一来源实体只有一个目标实体；正式名、昵称、姓氏和职衔均隶属同一编号，不随章改名。
- 不同角色不得合并，避免同名导致误认；相同姓氏可能源于亲属关系，按原关系保留，不强行要求人人不同姓。
- 同名异人先按关系、出场和身份区分。秘密身份与别名在台账关联，但正文不能提前向读者揭示。
- 地点保持相互位置、出行耗时、管辖与事件可达性。机构保持权限链。物件保持证据功能和获取途径。
- 复用概念按功能区分子条目，如“学校档案”与“警方档案”分别锁定，禁止同一个语义场景在不同章随意换制度。
- 人名选匹配现实化后角色年龄、出生年代、家庭及现代美国文化背景的常用姓名，不采用中世纪爵号代替现代身份。姓名用稳定中文译写，不凭善恶性格推定族裔、不把中国姓氏拼音化充当本地化。

## 现代候选映射：不是一对一词典

下表“来源”仅用于复审；目标正文使用中文名称，不保留英文对照。

| 来源元素 | 候选中文载体 | 必须核对的条件 |
|---|---|---|
| 派出所、公安局 | 市警察局、县警长办公室 | 城市/县辖区、职责与案件层级；不一律换联邦机构 |
| 法院流程 | 州法院、适用的小额诉讼程序 | 民事/刑事、争议类型、案件阶段；大陪审团不是普通审判或民事法院的同义词 |
| 公立医院、医保 | 医院、急诊室、私人保险或符合身份的公共医疗保障 | 不把所有医院改为私立，不默认人人享有同一保障；急救义务和后续费用问题分开 |
| 高考、班主任、年级 | 大学申请/入学评估、升学顾问/任课教师、相应学年 | 高考与 SAT 非制度等价；美国入学机制随年代和学校变化，不能把一次分数决定命运原样套用；顾问无班主任全部职责 |
| 小区、物业 | 公寓社区、物业管理公司、业主协会 | 租客/业主、住宅类型与合同权限；业主协会不能代行警方/法院职责 |
| 中式节庆、饭局 | 感恩节聚餐、后院烧烤、家庭聚会或适用的正式宴会 | 团聚/排斥/权力交易的功能、季节、时间间隔及重要道具；不是每顿饭都改烧烤 |
| 户籍、档案 | 居住证明、身份证明、教育/就业记录、背景审查 | 驾照、社会保障号码和背景审查各有不同用途，都不是户籍的万能替代；涉及权利限制要重验因果 |
| 方言梗、俗语 | 表达相同情绪与关系的中文译体口语 | 不直译典故、不强加地域刻板印象；谜底若依赖汉字则按核心文化风险处理 |

## 古代、仙侠与特殊机制的现代都市现实化

下列仅为功能候选，不是机械词典。为每项记录原机制、现代载体、成立条件、对后文的影响和是否需要核心改编授权。

- 皇权、宫廷、宗门、行会等组织，按原作用考虑企业董事会、职业协会、研究机构、家族企业或公共机构。必须拆清财产、雇佣与公权力：总裁不能判刑，协会不能合法处决成员，财富不等于刑事豁免。
- 庶嫡、赘婿、宗族等关系提取继承压力、经济依赖、家庭排斥与身份羞辱，改用可成立的现代家庭、婚姻及财产关系。不得宣称现代美国存在原作同款身份法或家长无限处置权。
- 修为、法宝、飞升、长生等先提取经验差距、稀缺资源、技术优势、职业机会和权力层级。可选履历、专利、证据、职位与机构准入等载体，但不把技术写成万能魔法，不用数千年寿命或瞬移解决现代事件。
- 神谕、诅咒、预言、轮回和穿越如只承担欺骗、误判或信息差功能，寻找有证据来源的现实机制；若它们确实决定核心事件，不能擅自宣布全是梦境、骗局或精神疾病。提出最小现实化方案并标明会改变什么，获明确授权后执行。
- 古代治病、审判与借贷统一转为现代美国医院、司法和金融场景，保留急迫、阻碍、代价与结果。现代医疗不能按原作灵丹效果保证痊愈；疑难机制按风险流程处理。
- 原有战争、远行和封闭环境需重新安排与美国都市生活的联系及现代时空条件，不能照搬旧战场加一个美国城市名。若要改变核心行动或胜负才能成立，须在计划中请求授权。

无法保真现实化时暂停受影响剧情链，仍以现代美国都市为唯一目标。不得为逃避冲突退回中世纪、都市奇幻或保留未经批准的源世界支线。

## 数值与文字机关

货币和计量可换载体，但须保留金额负担、资源稀缺程度、距离时间和人物选择的压力，不机械套实时汇率。精确数值是谜题或交易结果时，整条链联动核对。

中国字形、姓氏谐音、诗句暗号如承担关键证据，先寻找不改变获知顺序、难度与结果的目标语言机制；不能确认可成立就列为待复审，不凭中文译文编造所谓英文双关。
