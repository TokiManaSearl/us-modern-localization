# 文风与参考冲突裁决（文化转置适配）

本文件承接本技能的表达与因果参考，不启动旧网文去味流程。

优先顺序：本轮明确要求 → 本技能的现代美国都市、中文译体与剧情保护约定 → 本书已锁定计划 → 通用参考建议。当前任务不读取其他书或跨项目偏好；来源的中式文风不覆盖去除文化依赖的要求。

先读当前锁定计划中的文风和事实边界；没有独立文风文件不要求补建。保留视角、信息揭示顺序、动机和关系距离，不能为了自然表达添加新经历或提前揭底。

引用资源里的短句、压缩、去AI味、增补场景和检测阈值只作可选诊断线索，不得据此删除原有剧情、破坏翻译腔或自动运行未随包提供的脚本。事实与表达分开裁决，需改核心事件先取得授权。

文化残留的合理保留须按章节/位置给出原因，留在现有QA记录，不用泛词白名单关闭整类检测；具体要求见 [文化QA](../../cultural-transfer/qa-review.md)。
